# 答题系统（BlockAnswer）- 项目概览

## 项目简介

一个功能完整的 Web 端答题系统，基于 Next.js 和 React 构建。支持随机答题、实时改错、自动计分、错题分析等核心功能。

**项目名称：** BlockAnswer
**技术栈：** Next.js 15 + React 19 + TypeScript + Tailwind CSS
**开发时间：** 2024-11-07
**状态：** ✅ 完成（可投入生产）

## 核心功能

### 1. 答题功能 ✅
- 四选一单选题
- 随机题目顺序
- 实时选项切换
- 进度指示器

### 2. 改错功能 ✅
- 提交后立即显示答案
- 色彩编码反馈（正确绿色、错误红色）
- 正确答案提示
- 详细错题分析

### 3. 计分功能 ✅
- 自动计算得分
- 计分规则：每题 0.7 分，满分 100 分
- 正确率计算
- 成绩汇总报告

### 4. 进度管理 ✅
- 自动保存进度到 LocalStorage
- 支持进度恢复
- 题目导航快速跳转
- 重新答题功能

### 5. 数据支持 ✅
- 支持 130+ 道题目
- JSON 格式数据
- 自动采集脚本
- 手动编辑支持

## 功能详解

### 1. 答题流程

```
初始化
  ↓
[加载题目] → 从 JSON 读取 + 随机排列
  ↓
[显示界面] → 当前题目 + 导航栏
  ↓
[用户交互] ← 点击选项 → 保存答案
  ↓
[循环] ← 上一题/下一题/跳转
  ↓
[提交] → 计算分数 → 对比答案
  ↓
[显示结果] → 成绩 + 错题分析
  ↓
[重新答题] → 返回初始化
```

### 2. 本地存储

使用 Browser LocalStorage API 存储：

```javascript
// 保存进度
{
  "quiz_main-quiz": {
    "currentIndex": 5,
    "answers": [
      { questionId: 1, userAnswer: "C", isCorrect: true },
      { questionId: 2, userAnswer: "A", isCorrect: false },
      // ... 更多答案
    ]
  }
}
```

**优点：**
- 无需后端数据库
- 数据持久化
- 用户隐私保护
- 快速加载

### 3. 计分算法

```typescript
// 计分规则
const POINTS_PER_QUESTION = 0.7;
const MAX_SCORE = 100;

function calculateScore(answers: Answer[]): number {
  const correctCount = answers.filter(a => a.isCorrect).length;
  const rawScore = correctCount * POINTS_PER_QUESTION;
  return Math.min(rawScore, MAX_SCORE);
}

// 示例
/*
对于 130 道题：
- 100 题正确: 100 × 0.7 = 70 分
- 130 题正确: 130 × 0.7 = 91 分（<100）
- 143 题正确: 143 × 0.7 = 100.1 → 100 分（取最小值）
*/
```

### 4. 数据采集

采集脚本流程：

```javascript

const CONFIG = {
  courseId, classId, workId, workAnswerId, enc, ...
}

  // ...
}

// 3. 正则解析 HTML

// 提取：题干、选项A-D、正确答案

// 4. 保存为 JSON
```

**特点：**
- 支持 0-based 和 1-based index（自动检测）
- 自动重试机制
- 速率限制（500ms 延迟）
- 生产就绪
