# 题目数据采集指南

## 方法 1：使用自动采集脚本（推荐）

### 准备工作

1. **获取 Cookie** - 在浏览器中访问答题页面，打开开发者工具获取 Cookie
2. **获取URL参数** - 从答题URL中复制以下参数：
   - `courseId` - 课程 ID
   - `classId` - 班级 ID
   - `workId` - 作业 ID
   - `workAnswerId` - 答题 ID
   - `enc` - 加密参数
   - `knowledgeid` - 知识点 ID

### 采集步骤

1. **编辑脚本**

```bash
vim scripts/fetch-questions.js
```

2. **更新配置参数**

找到 `CONFIG` 对象和 `COOKIES` 常量，替换成你的实际值：

```javascript
const CONFIG = {
  courseId: 'YOUR_COURSE_ID',
  classId: 'YOUR_CLASS_ID',
  workId: 'YOUR_WORK_ID',
  workAnswerId: 'YOUR_WORK_ANSWER_ID',
  enc: 'YOUR_ENC',
  knowledgeid: '0',
  mooc: '1',
  source: '0',
  keyboardDisplayRequiresUserAction: '1',
};

const COOKIES = 'YOUR_COOKIES_HERE';
```

3. **测试采集**

```bash
node scripts/fetch-questions.js
```

脚本会先尝试采集前 3 题进行测试。

4. **开启完整采集**

如果测试成功，编辑脚本将最后一行改为：

```javascript
const testQuestions = await fetchAllQuestions(130);
```

然后重新运行脚本：

```bash
node scripts/fetch-questions.js
```

5. **检查结果**

采集完成后，题目会保存到 `data/questions.json`。

## 方法 2：手动编辑 JSON

### 格式规范

```json
[
  {
    "id": 1,
    "question": "题目文本内容",
    "options": {
      "A": "选项 A 的文本",
      "B": "选项 B 的文本",
      "C": "选项 C 的文本",
      "D": "选项 D 的文本"
    },
    "correctAnswer": "C"
  },
  {
    "id": 2,
    "question": "第二个题目",
    "options": {
      "A": "选项 A",
      "B": "选项 B",
      "C": "选项 C",
      "D": "选项 D"
    },
    "correctAnswer": "B"
  }
]
```

### 注意事项

- `id` 必须是唯一的整数，从 1 开始
- `correctAnswer` 必须是 "A"、"B"、"C" 或 "D" 之一
- 确保 JSON 格式正确（可用 JSON 验证工具检查）
- 题目文本不要包含 HTML 标签

## 方法 3：从 HTML 中提取

如果是 HTML 页面形式，可以按照以下步骤手动提取：

1. **保存 HTML** - 右键点击页面 → 另存为，保存为 HTML 文件
2. **解析 HTML** - 手动或使用脚本从 HTML 中提取题目、选项、答案
3. **转换为 JSON** - 整理成上述 JSON 格式

### 示例：从课程网站页面手动提取

```javascript
// 在浏览器控制台运行以下代码
const questions = [];
document.querySelectorAll('.question-block').forEach((block, idx) => {
  const questionText = block.querySelector('.question-text')?.textContent || '';
  const options = {};
  ['A', 'B', 'C', 'D'].forEach(letter => {
    options[letter] = block.querySelector(`.option-${letter}`)?.textContent || '';
  });
  const answer = block.getAttribute('data-answer');
  questions.push({ id: idx + 1, question: questionText, options, correctAnswer: answer });
});
console.log(JSON.stringify(questions, null, 2));
```

然后复制输出内容到 `data/questions.json`。

## 采集脚本详解

### 脚本工作流程

```
1. 读取配置和 Cookie
   ↓
2. 循环请求每一题（index = 1 到 130）
   ↓
3. 解析 HTML 响应
   ↓
4. 提取：题干、选项 A/B/C/D、正确答案
   ↓
5. 保存到数组
   ↓
6. 写入 data/questions.json
```

### 脚本参数

| 参数 | 含义 | 示例 |
|------|------|------|
| `courseId` | 课程 ID | 253005396 |
| `classId` | 班级 ID | 122331352 |
| `workId` | 作业 ID | 47765867 |
| `workAnswerId` | 答题 ID | 54536440 |
| `enc` | 加密参数 | 1566b35702... |
| `knowledgeid` | 知识点 ID | 0 |
| `index` | 题目索引 | 1-130 |

### HTML 解析规则

脚本会查找以下 HTML 结构：

```html
<!-- 题干 -->
<div class="ans-cc timuStyle">题目内容</div>

<!-- 选项 -->
<span orichoice="A">A</span>
<div id="A" class="centerSpan">选项内容</div>

<!-- 正确答案 -->
<div class="answerRight">
  <span>C</span>
</div>
```

如果网页 HTML 结构不同，需要修改脚本中的正则表达式。

## 常见问题

### Q: Cookie 过期了怎么办？
A: 重新登录，在开发者工具 → Network 标签中找一个成功的请求，复制新的 Cookie 值。

### Q: 采集失败（0 题）怎么办？
A:
1. 检查 Cookie 是否过期
2. 检查 URL 参数是否正确
3. 检查网络连接
4. 查看脚本输出的错误信息

### Q: 采集速度太慢怎么办？
A: 编辑脚本中的延迟参数：

```javascript
await new Promise(resolve => setTimeout(resolve, 500)); // 改为更小的值，如 200
```

但不要设置太小，否则可能被服务器限流。

### Q: 如何只采集前 50 题？
A: 将脚本最后的 `fetchAllQuestions(130)` 改为 `fetchAllQuestions(50)`。

### Q: 采集到的题目有 HTML 标签怎么办？
A: 检查脚本的正则表达式是否正确。如需清理，可用以下代码：

```javascript
// 移除 HTML 标签
function stripHtml(html) {
  return html.replace(/<[^>]*>/g, '').trim();
}
```
