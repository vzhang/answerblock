# 快速开始指南

## 第一步：准备题目数据

### 选项 A：使用示例题目（快速开始）

系统已包含 3 道示例题目。直接启动应用进行测试。

### 选项 B：导入实际题目数据

#### 方式 1：手动编辑 JSON（推荐新手）

1. 打开 `data/questions.json`
2. 按照以下格式添加题目：

```json
[
  {
    "id": 1,
    "question": "题目内容",
    "options": {
      "A": "选项A",
      "B": "选项B",
      "C": "选项C",
      "D": "选项D"
    },
    "correctAnswer": "C"
  },
  {
    "id": 2,
    "question": "第二题...",
    "options": {
      "A": "...",
      "B": "...",
      "C": "...",
      "D": "..."
    },
    "correctAnswer": "B"
  }
]
```

3. 保存文件

#### 方式 2：使用自动采集脚本

详见 [数据采集指南](./数据采集指南.md)

## 第二步：启动应用

### 方式 1：开发模式（推荐开发）

```bash
# 进入项目目录
cd blockanswer

# 安装依赖（如果还没安装）
npm install

# 启动开发服务器
./scripts/dev.sh
```

输出应该显示：

```
▲ Next.js 15.4.0
- ready - started server on 0.0.0.0:3000, url: http://localhost:3000
```

然后打开浏览器访问：`http://localhost:3000`

### 方式 2：生产模式（推荐部署）

```bash
# 构建项目
./scripts/build.sh

# 启动生产服务器
npm start
```

访问：`http://localhost:3000`

## 第三步：开始答题

### 界面说明

```

│  答题测试系统                                     │
│  共 130 道题，每题 0.7 分，满分 100 分            │
├──────────────┬──────────────────────────────────┤
│ 题目导航     │ 题目卡片                           │
│              │                                  │
│ 1  2  3  4   │ 第 1 / 3 题                      │
│ 5  6  7  8   │ 题目内容：在 TCP/IP...            │
│ ...          │                                  │
│              │ ○ A. IP(Internet 协议)           │
│ 已作答: 2/3  │ ○ B. TCP(传输控制协议)           │

│              │ ○ D. UDP(用户数据协议)           │

│  [上一题]  [下一题]  [提交答卷]                   │
└─────────────────────────────────────────────────┘
```

### 使用步骤

1. **选择答案** - 点击任意选项
   - 选中会高亮显示为蓝色
   - 可以随时更换答案

2. **浏览题目** - 左侧导航栏
   - 点击任意题号快速跳转
   - 灰色 = 未作答
   - 绿色 = 正确答案（提交后）
   - 红色 = 错误答案（提交后）

3. **提交答卷** - 点击"提交答卷"按钮
   - 所有题目会被锁定
   - 显示你的答案和正确答案

4. **查看成绩**

显示以下信息：
- 总分（0-100 分）
- 正确题数和错误题数
- 正确率百分比
- 进度条

### 成绩计算

```
分数 = 正确题数 × 0.7 分/题

例如：
- 50 道题全对：50 × 0.7 = 35 分
- 100 道题全对：100 × 0.7 = 70 分
- 130 道题全对：130 × 0.7 = 91 分（>100分，取 100）
- 143 道题全对：143 × 0.7 = 100 分（100 分封顶）
```

## 第四步：查看错题分析

提交后，点击"查看错题分析"：

- 显示所有错题
- 你的答案 ✗
- 正确答案 ✓
- 便于复习

## 常见操作

### 重新答题

点击"重新答题"按钮：

- 清除所有进度
- 题目重新随机排列
- 开始新一轮测试

### 继续上一次

- 刷新页面即可恢复进度
- 从上次停止的位置继续答题
- 进度自动保存到浏览器

### 清除数据

在浏览器开发者工具中：

1. 打开 DevTools (F12)
2. 进入 Application → Local Storage
3. 找到 `quiz_main-quiz` 条目
4. 删除即可

或直接点击"重新答题"按钮。

## 界面功能详解

### 顶部栏

- 标题：答题测试系统
- 描述：总题数、每题分值、满分

### 左侧导航栏（题目导航）

- **题号按钮** - 点击快速跳转到该题
- **颜色编码**
  - 蓝色：当前题目
  - 绿色：已作答且正确（仅提交后显示）
  - 红色：已作答但错误（仅提交后显示）
  - 灰色：未作答
- **统计信息**
  - 已作答数 / 总数
  - 正确数（仅提交后显示）

### 中间内容区

#### 题目卡片

- **进度指示** - 第 X / 总数 题
- **题干** - 题目文本
- **选项** - A、B、C、D 四个选项
- **选中标记** - 当前选中选项有对号

提交后额外显示：

- 你的答案（蓝色框）
- 正确答案（如果错误）

#### 按钮区

- **上一题** - 跳转到上一题（灰显如无上一题）
- **下一题** - 跳转到下一题（灰显如无下一题）
- **提交答卷** - 提交所有答案进行批改（提交后隐藏）

## 故障排除

### 网页一直显示"正在加载题目..."

**可能原因：**
- 题目文件加载失败
- JavaScript 加载失败

**解决方案：**
1. 检查浏览器控制台是否有错误（F12）
2. 检查 `data/questions.json` 文件是否存在且有效
3. 刷新页面

### 答案保存不了

**可能原因：**
- 浏览器禁用了 localStorage
- 隐私模式

**解决方案：**
1. 关闭隐私/无痕模式
2. 检查浏览器设置，允许本地存储
3. 在控制台运行 `localStorage.getItem('quiz_main-quiz')` 测试

### 题目显示异常

**可能原因：**
- JSON 格式错误
- 缺少必要字段

**解决方案：**
1. 检查 `data/questions.json` 的 JSON 格式
2. 使用 JSON 验证工具 (如 jsonlint.com)
3. 确保每题都有 id、question、options、correctAnswer
