# 部署指南

## 部署选项总结

| 平台 | 难度 | 费用 | 推荐度 | 优点 |
|------|------|------|--------|------|
| **Vercel** | ⭐ | 免费 | ⭐⭐⭐⭐⭐ | 一键部署，自动 HTTPS |
| **Netlify** | ⭐ | 免费 | ⭐⭐⭐⭐ | 简单快速 |
| **GitHub Pages** | ⭐⭐ | 免费 | ⭐⭐⭐ | 需要静态生成 |
| **自托管 VPS** | ⭐⭐⭐ | 付费 | ⭐⭐ | 完全控制 |

## 方案 1：部署到 Vercel（推荐）

### 优点

- ✅ Next.js 官方推荐
- ✅ 免费额度充足
- ✅ 自动 HTTPS
- ✅ 全球 CDN
- ✅ 一键部署
- ✅ 自动构建和部署

### 步骤

#### 1. 创建 GitHub 仓库

```bash
cd blockanswer
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/YOUR_USERNAME/blockanswer.git
git branch -M main
git push -u origin main
```

#### 2. 访问 Vercel

1. 打开 [vercel.com](https://vercel.com)
2. 用 GitHub 账号登录
3. 点击 "Import Project"
4. 选择你的 `blockanswer` 仓库
5. 点击 "Import"

#### 3. 配置构建设置

Vercel 会自动检测到 Next.js 项目，默认设置通常无需修改：

- **Build Command**: `npm run build` ✓
- **Output Directory**: `.next` ✓
- **Install Command**: `npm install` ✓

#### 4. 完成部署

1. 点击 "Deploy"
2. 等待构建完成
3. 获得你的 Vercel URL (如 `https://blockanswer.vercel.app`)

#### 5. 自动部署

每次推送到 GitHub 时：

```bash
git add .
git commit -m "Update questions"
git push
```

Vercel 会自动重新构建和部署。

### 自定义域名（可选）

1. 在 Vercel 项目设置中找到 "Domains"
2. 输入你的域名
3. 按照提示修改 DNS 设置

## 方案 2：部署到 Netlify

### 步骤

#### 1. 安装 Netlify CLI

```bash
npm install -g netlify-cli
```

#### 2. 连接到 Netlify

```bash
netlify login
```

#### 3. 初始化部署

```bash
cd blockanswer
netlify init
```

按照提示：
- 选择 "Create & configure a new site"
- 输入 site 名称
- 构建命令：`npm run build`
- 发布目录：`.next`

#### 4. 部署

```bash
netlify deploy --prod
```

## 方案 3：部署到 GitHub Pages（静态生成）

### 注意

GitHub Pages 只支持静态内容。由于应用使用 localStorage，理论上可行，但需要静态导出。

### 步骤

#### 1. 修改 next.config.js

```javascript
/** @type {import('next').NextConfig} */
const nextConfig = {
  output: 'export',
  reactStrictMode: true,
};

module.exports = nextConfig;
```

#### 2. 构建

```bash
npm run build
```

这会在 `out` 目录生成静态文件。

#### 3. 部署

```bash
git add .
git commit -m "Deploy to GitHub Pages"
git push origin main
```

在 GitHub 仓库设置中：

1. 找到 "Pages"
2. Source 选择 "Deploy from a branch"
3. Branch 选择 "main"
4. 文件夹选择 "/ (root)"
5. 保存

稍等几分钟，网站会发布到 `https://YOUR_USERNAME.github.io/blockanswer`

## 方案 4：自托管 VPS

### 环境要求

- Node.js 18+
- npm 或 yarn

### 步骤

#### 1. 连接到 VPS

```bash
ssh root@YOUR_SERVER_IP
```

#### 2. 安装 Node.js

```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs
```

#### 3. 克隆项目

```bash
cd /home
git clone https://github.com/YOUR_USERNAME/blockanswer.git
cd blockanswer
```

#### 4. 安装依赖和构建

```bash
npm install
npm run build
```

#### 5. 启动应用

**选项 A：使用 PM2（推荐）**

```bash
# 全局安装 PM2
sudo npm install -g pm2

# 启动应用
pm2 start npm --name "blockanswer" -- start

# 设置开机自启
pm2 startup
pm2 save
```

**选项 B：使用 systemd**

创建 `/etc/systemd/system/blockanswer.service`：

```ini
[Unit]
Description=BlockAnswer Quiz Application
After=network.target

[Service]
Type=simple
User=nobody
WorkingDirectory=/home/blockanswer
ExecStart=/usr/bin/npm start
Restart=always

[Install]
WantedBy=multi-user.target
```

启动服务：

```bash
sudo systemctl start blockanswer
sudo systemctl enable blockanswer
```

#### 6. 配置 Nginx 反向代理

```nginx
server {
    listen 80;
    server_name YOUR_DOMAIN.com;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

重启 Nginx：

```bash
sudo systemctl restart nginx
```

#### 7. 配置 HTTPS（使用 Let's Encrypt）

```bash
sudo apt-get install certbot python3-certbot-nginx
sudo certbot --nginx -d YOUR_DOMAIN.com
```

## 构建优化

### 生产构建

```bash
npm run build
```

输出应该显示：

```
Route (app)                                 Size
┌ ○ /                                    3.61 kB
└ ○ /_not-found                             1 kB
+ First Load JS shared by all             100 kB
```

### 性能优化

1. **启用 Gzip 压缩** - 大多数 CDN 自动启用
2. **图片优化** - 使用 Next.js Image 组件
3. **代码分割** - Next.js 自动处理
4. **缓存策略** - 配置在 `next.config.js`

## 故障排除

### 部署后显示 404

**原因：** 构建命令错误或输出目录配置错误

**解决：**
- 检查构建日志
- 确保 `.next` 目录存在
- 验证 `next.config.js` 配置

### 样式不显示

**原因：** CSS 文件加载失败

**解决：**
- 清除浏览器缓存
- 检查 base URL 配置
- 确保 Tailwind CSS 正确编译

### 数据加载不出来

**原因：** `questions.json` 路径错误或文件不存在

**解决：**
- 确保 `data/questions.json` 文件存在
- 检查文件是否被部署
- 验证 JSON 格式正确
